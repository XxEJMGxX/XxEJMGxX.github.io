# 🚀 Elías Nieto - Portfolio

Web Application Development student (2º DAW) based in Madrid, Spain. This repository contains the source code and architecture of my personal portfolio, designed to showcase full-stack web projects, desktop applications, and UI/UX design implementations.

## 💻 Tech Stack & Tools

*   **Frontend & UI/UX:** HTML5, CSS3, JavaScript, Figma, Canva.
*   **Backend & Architecture:** Java (MVC Pattern), PHP, Python.
*   **Databases:** MySQL, MariaDB.
*   **Infrastructure & Virtualization:** Local environments (XAMPP), Oracle VirtualBox, Docker.
*   **Development Tools:** Git, GitHub, VS Code, Maven.

## 📂 Featured Projects

*   **[Java Quiz](https://github.com/XxEJMGxX/Java-Quiz):** Interactive desktop application developed with JavaFX. Features a strict separation of business logic and user interface through a modular Model-View-Controller (MVC) architecture.
*   **[Sabor Binacional](https://github.com/XxEJMGxX/Sabor-Binacional):** Interactive frontend web platform (HTML/CSS/JS) focused on showcasing the gastronomic and cultural fusion between Venezuela and Colombia.
